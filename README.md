# Python Dictionary Methods

## Explanation

Python dictionaries provide several built-in methods for accessing, updating, and removing key-value pairs.

## Problem Statement

Write a Python program that creates a dictionary and demonstrates commonly used dictionary methods.

## Features

* Displays dictionary keys
* Displays dictionary values
* Displays key-value pairs
* Accesses values using `get()`
* Updates dictionary data
* Removes an entry using `pop()`

## How It Works

The program creates a student dictionary and uses different dictionary methods.

### Methods Used

* `keys()` – returns all keys
* `values()` – returns all values
* `items()` – returns key-value pairs
* `get()` – accesses a value using a key
* `update()` – adds or updates entries
* `pop()` – removes an entry

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Create a dictionary.
3. Display the keys.
4. Display the values.
5. Display the key-value pairs.
6. Access a value using `get()`.
7. Update the dictionary.
8. Remove an entry using `pop()`.
9. Display the final dictionary.
10. End the program.

```text id="c4p8mx"

Values: dict_values(['Harini', 20, 'CSE', 'Hyderabad'])
```
